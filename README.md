# lilirubio.es

Portfolio de Lili Rubio · UX/UI y diseño de producto.

- **Diseño:** Figma (fuente de verdad del diseño y del copy).
- **Código:** Astro (sitio estático). Tokens en `src/styles/tokens.css`, generados desde las variables de Figma (primitivas → semánticas → componente; modo móvil por defecto y desktop a partir de 960 px).
- **Publicación:** Vercel, dominio lilirubio.es.

## Desarrollo

```
npm install
npm run dev
```
